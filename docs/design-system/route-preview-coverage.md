# Route-to-preview coverage matrix

Generated from source plus explicitly reviewed mappings in [route-previews.mjs](../../scripts/design-system/route-previews.mjs).

An interactive mapping establishes view/section composition parity only. It never proves route-controller, authorization, SSR, backend mutation or runtime parity. Other linked stories are direct module-import relationships and may cover an excerpt; they are not page previews. Missing composition coverage stays explicit. The generic Admin Workspace story is a pattern demonstration and is deliberately not mapped to a product route.
